# algo-snoop

«Алгоритмический детектив» — игровой тренажёр для задач из списка NeetCode 150 на JavaScript.

Каждая задача — это «дело», которое проходит 10 сцен: от понимания условия и крайних случаев до брутфорса, выбора паттерна, плана, кода и итогового правила. За сцены начисляется XP, растут ранги (от Стажёра до Шерлока), открываются награды.

## Возможности

- Страница задачи в стиле NeetCode: условие слева, редактор с подсветкой и консоль справа, кнопки «Запустить» и «Отправить».
- Полный список NeetCode 150 с сортировкой по сложности, поиском, фильтрами и избранным.
- Для 6 задач Arrays & Hashing (Contains Duplicate, Valid Anagram, Two Sum, Group Anagrams, Top K Frequent Elements, Longest Consecutive Sequence) есть тесты, которые запускаются прямо в браузере, включая большие входы.
- Остальные задачи открываются по ссылке на NeetCode: условие вставляешь сам, дальше те же 10 сцен.
- Наставник на базе Claude оценивает ответы, даёт намёки и объясняет идею решения, но не пишет готовый код.

## Как запустить

Открой `index.html` в браузере. Тесты кода и прогресс (в `localStorage`) работают сразу.

Наставник и сохранение прогресса в облаке работают, только когда страница открыта как Claude Artifact: они используют возможности `sample`, `db` и `user` из среды Claude. В обычном браузере страница покажет, что наставник недоступен, а всё остальное продолжит работать.

## Структура

```
src/app.html       исходник страницы в формате Claude Artifact
index.html         самостоятельная страница, собирается из src/app.html
scripts/build.js   сборка index.html
```

После правок в `src/app.html` пересобери страницу:

```bash
node scripts/build.js
```
